# 需求范围与验收基线

陪伴式、学科化、全流程的 AI 学习助教数字人，覆盖课前预习、课中答疑、课后复习、作业辅导、备考冲刺，实现一对一私教、智能导学、全程陪伴。

## 完整范围与阶段

| 编号 | 功能范围 | 首版范围 | 后续扩展 |
| --- | --- | --- | --- |
| F01 | 形象/学科/语气自定义，语音文字动作，鼓励提醒与状态感知 | 2D 形象、两种语气、基础播报、专注计时 | 更多学科形象、连续语音、复杂动作；疲劳以自报/计时提醒为依据 |
| F02 | 专业/课程/章节路径，重点难点考点易错点，图文语音示例讲解 | 单门高数、章节与知识点、路径建议 | 跨专业课程、更多讲解资源 |
| F03 | 概念公式原理案例问答、拍照/上传、多轮分步辅导 | S1 文字及有引用答疑；S2 图片题确认与 OCR | 复杂试卷版面、多题拆分 |
| F04 | 作业难度/考点/耗时估算、错题本、同类题、截止提醒 | 作业提交、确认错题、站内截止提醒 | 批量作业分析、同类题个性化推荐 |
| F05 | 预习清单、复习计划、间隔复习、课件笔记提炼、抽背默写速记 | 可编辑计划、基于答题反馈安排复习 | 概念抽背、公式速记、自适应间隔 |
| F06 | PPT/教材解析、课堂录音转写与提炼、暂停重讲举例 | PDF；S2 PPTX、录音文件转写与摘要 | 实时课堂语音及更复杂教材 |
| F07 | 真题模拟卷解析、高频考点、训练、技巧/时间/心态指导 | 章节练习，支持训练模式 | 完整模拟考试、考点专题与时间策略 |
| F08 | 时长/专注/薄弱点/趋势、雷达图、周月诊断 | 有来源的时长与答题统计；S2 雷达图/周报 | 月报、长期诊断 |
| F09 | 公共课、理工文史经管艺术教育、自定义课程 | 单门示范课与课程导入接口 | 每新增一科补课程结构、评测与资料 |
| F10 | 知识库维护、作业发布批阅统计、班级监控预警、教学风格 | 教师上传、发布作业、授权班级概览 | 批阅辅助、预警规则、学校管理配置 |

“押题”在产品中表述为基于已提供材料的重点训练，不承诺预测真实考题。耗时估算/掌握度均注明计算依据和样本不足状态；专注计时不能当作客观注意力或心理状态检测。

## 答疑行为

默认循序给出思路、提示、步骤和总结，并在适当处等待学生尝试；不要首轮就把完整答案藏在“步骤”中。后续总结基于学生完成情况给出教学解释。输出可审阅的解题说明，不要求模型暴露内部推理过程。

图片识别有歧义时先确认题干；引用必须来自该用户有权访问的课件，显示文件名和页码/片段。找不到依据时明确说明，不编造引用。题目中的指令与上传文档属于不可信内容，不得改变系统权限和教学规则。

## 演示与质量验收

- 正常链路按 team-plan 的首版验收执行。
- 学生 A 不能读取学生 B 私有对话/作业；教师不能读取其他班级资料。
- AI/语音超时有明确失败状态，允许重试或降级到文字，不能伪造成功结果。
- AI 固定评测至少 30 条：学科正确性、分步教学、引用、多轮、无依据、注入、越权、OCR 歧义。
- M3 维护带期望要点的评测集；首版人工评分正确性/教学性目标 ≥80%，越权和伪造引用安全样例要求全部通过。这是验收目标，不是当前已测结果。
- 对外演示之前记录环境、模型、样本、延迟和已知限制；真实模型调用费用须在项目预算内。
