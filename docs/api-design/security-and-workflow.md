# 接口规范与安全验收

以下为v2实现必须满足的设计和验收目标，不是当前服务已具备这些能力的声明。

## 请求与响应

HTTP方法表达读/创建/局部修改/删除，URL以资源名为主；health、auth/login、auth/logout、me、stop和只读batch-queries为已解释的协议/动作例外。除公开health/login外均携带Authorization: Bearer，不能放query。服务端每次新建trace_id，响应X-Request-ID一致；浏览器不能覆盖actor、trace、成绩或教学阶段。

v2 JSON响应固定code、message、data、trace_id。成功code=0；错误数值码以1xxxx参数、2xxxx业务/权限、5xxxx系统分组，并使用真实4xx/5xx。204严格无体，二进制下载和text/event-stream不套整个JSON对象。列表data固定items/total/page/page_size，空列表为[]；默认page=1/page_size=20，上限100，最多1000页。所有查询先按授权范围过滤再计算total；更深导出另走受控异步任务，不开放无限爬取。

默认sort仅允许created_at/-created_at并以id作稳定次序。其他排序需求必须加入显式schema白名单，不能拼接任意ORDER BY。from/to为UTC半开区间，custom必须同时提供且from<to，最长366天；timezone用ZoneInfo校验，不假定一天固定86400秒。PATCH只接受白名单字段且至少一项；缺省不修改，null只有nullable字段表示清空。引用ID须验证父子和同课程关系，FK存在不证明访问许可。

## 幂等与并发

写操作按接口要求携带Idempotency-Key；认证登录不缓存密码请求/凭证结果，logout和stop利用自身幂等。键按actor+操作+目标资源隔离，服务端保存规范化参数摘要。首次请求原子登记，重复同键同参数不重复写业务/错题/事件，同键换参409；并发同键只能一个生效。先重新校验当前权限，再读幂等结果；不能缓存授权永不过期。

PATCH带If-Match并采用条件更新，过期版本412。重复相同幂等请求先返回已保存结果，避免已成功的重试被新ETag误判；键重用换参数仍409。业务对象存活期内保留稳定去重依据，短期结果缓存过期不等于可再次执行同一写入。服务端错误回滚不得留下“成功”去重记录。

SSE同键已有轮次返回409和仅当前owner可见的turn_id，不再次计费；重新提问使用新键。这是副作用幂等，不是断点续传。临时断连不得自动新建轮次；客户端先查询轮次状态，由用户决定是否重试。

## 身份 角色 与对象权限

M1验证JWT签名/过期/撤销和账号当前状态。M5持有唯一enrollments/teaching_assignments，提供公开读写service；M1的选课HTTP只调用它。学生自助入班先创建申请，批准前没有课程访问权；教师只管理有效授课班级；admin也需要明确管理范围，不默认读取私有完整对话、录音或标准答案。

未认证401，角色禁止403，对象不存在/越权均404。每次请求、后台worker执行、下载和历史引用读取均重新检查对象归属。用户A换成B的ID、同课程双班、转班前后、文档撤权和并发更改必须各有反例测试。查询班级统计按历史事件class快照聚合，再按教师当前授权范围裁剪，不向新班泄露旧班数据。

## 文件 模型 与隐私

JSON请求默认上限1MiB；文件上限20MiB并流式累计大小。PDF最多200页，PPTX/DOCX最多200页或幻灯片；归档展开总量上限100MiB、压缩比上限100，解析30秒超时并隔离进程。校验扩展名、MIME和魔数一致；不接受任意远程URL，防SSRF。加密/损坏/超限文件返回明确失败，不无限重试。上述数值是本设计默认上限，部署须配置并实测，不是已完成压测证据。

存储key不公开；原文件下载必须鉴权、no-store、attachment并净化文件名。上传课件、检索片段和模型输出均为不可信数据，不执行其中命令，不允许其授予访问权限。SQL参数化，Markdown禁原始HTML，富文本按白名单净化，输出文本转义，CSP由前端/网关落实。

密码仅加盐哈希；密钥仅环境/Secret服务。认证成功响应可交付当前Token，但其他DTO、URL、审计、错误和日志不得包含密码/Token/连接串。日志只保留trace、脱敏动作、状态、耗时、版本和必要token用量，不记录完整问答/录音/课件正文。测试只用合成账号与获许可材料。

录音前确认用途、有效告知版本和同意；拒绝不录音且保留文字路径。真实数据收集前确定保留期限、撤回、对象/派生文本/缓存/备份清理策略，未确认不收真实学生资料。先撤回阻断使用，再经授权清理，不以RESTRICT永久拒删，不自动CASCADE整组数据。

## 限流 超时 与可观测性

仅本机显式开发可HTTP；生产HTTPS、HSTS和允许来源CORS，不能以CORS代替鉴权。登录建议按IP+账号5次/5分钟；普通API按用户60次/分钟；模型/媒体任务按用户10次/分钟、同时最多2个。达到上限429+Retry-After，配额失败不创建重复任务。数值为待测设计配置，不声称网关已启用。

普通JSON请求5秒总超时；SSE模型首包目标3秒、整轮上限120秒，5秒用户停止兜底；异步任务有最大尝试次数和终止状态。GET私有数据no-store；公共静态资源可用ETag，写后失效；ETag仍可用于私有PATCH防覆盖，不意味着共享缓存私有数据。

候选性能门槛：100并发、1万条合成记录，普通读P99≤500ms、普通写P99≤1000ms；文件/模型单独按任务排队、首包和完成时延测量，不把外部模型耗时藏进普通读指标。当前未执行此压测。观测按接口/状态/耗时统计，避免用户ID高基数标签和敏感正文。

浏览器JWT业务不内嵌HMAC共享密钥。未来确需服务间回调时才独立设计mTLS或签名认证：原始body摘要+timestamp+nonce，服务端允许±5分钟并持久去重，密钥轮换，回调重放不能重复结算。本批未声明任何真实供应商回调已接入。

## 工具链与发布前门禁

设计源生成OpenAPI、类型、Postman集合及Word参数表；修改源后重新生成，CI用--check拒绝漂移。Apifox/Swagger导入只验证描述可用，Mock场景必须显示is_mock；schema校验和Mock不能替代真实HTTP、权限、PG迁移/回滚/重启、worker并发与浏览器全链路。

上线前逐项验：资源方法/状态、统一响应、版本、参数/分页白名单、幂等/并发、规范文件入Git；TLS/认证/RBAC/owner校验、输入与SQL/HTML防护、限流、敏感信息、文件生命周期和错误脱敏。门禁状态分别记录已设计、自动静态验证、真实集成通过、待执行，禁止只写“全部通过”。

PR写明AI辅助范围、实际命令和结果；至少两名非作者/相关领域消费者审查公共接口。实现使用小任务分支，未经授权不合并、部署、删除真实数据或改账户设置。v2候选本身不授权跳过这些门禁。
