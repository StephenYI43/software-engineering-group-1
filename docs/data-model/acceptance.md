## 0. 使用规则（违反任何一条，记录作废）

1. **没跑过就不填。** 没执行的写「未运行」，不写「应该通过」「待验证」以外的主观判断。
2. **一格一条证据。** 每条至少包含：执行的命令、原始输出里的关键行、执行时间与 commit。
   只写「已验证」不算证据。
3. **标明层级。** `repository` / `API` / `UI` 三档分开记。UI 只认真实接口返回 + 页面截图，
   **fixture 渲染、`?mock=` 场景截图一律不算**（`docs/data-model/student.md` 第 7 节）。
4. **不得替代。** 内存实现、SQLite、单测绿灯都不能代替 PostgreSQL 证据；
   数据库身份自增也不等于提交顺序（#69「持久化共同基线」）。
5. **重启是真重启。** 关闭 API 进程 + 重启 PostgreSQL 容器并保留数据卷，再读回；
   同一个连接内读回不算重启验收。
6. **破坏性操作只在临时库。** 降级、删卷、清表只在明确标注的临时测试库执行，不碰保留卷。
